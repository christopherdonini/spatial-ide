# docs/experiments/

Unscheduled preregistrations only — written in advance of need, before anyone is invested in the
outcome, on the ADR-012 pattern. A document filed here binds nothing and may not be cited to justify
starting the work it describes. Once the work is scheduled, the document moves to the module
directory that owns it (per `protocol/transport-bakeoff/README.md`'s precedent) and is no longer
listed here.

A preregistration's own text is frozen once filed — additions arrive as **dated companion notes
beside it** (`*-COMPANION-<date>.md`), which carry the same binds-nothing standing and move with
their parent when the work is scheduled.
