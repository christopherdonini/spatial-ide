- Development-time AI practices live in `AI_DEVELOPMENT.md`, deliberately outside the constitution.
- `docs/experiments/` holds unscheduled preregistrations only (see its own `README.md`) — **each filed preregistration is append-only and is not edited after filing** (the directory's own `README.md` may still evolve). A filed document binds nothing and moves to the module directory that owns the work once scheduled.
- Unresolved decisions are marked inline as `> OPEN:` blocks. Each names the doc/phase where it must be resolved.
- Changing 01 requires an ADR explaining why a first principle failed.
