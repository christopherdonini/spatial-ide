68. **A filter change made while the previous data load is finishing can leave the new view unfilled until you pan or zoom, and the status line can still say that all features in view are shown.**
    An Apply or a Clear starts a new first data load. If the previous first data load is still running then, the app goes on treating it as the current one for a short moment, until the new load's stream has been set up. When the previous load completes inside that moment, the map asks for tiles of the view it shows at that instant, under the new filter, as it does when a first data load of a view completes (item 64). When the new load itself completes, the map then asks for no tiles of the view it shows; it asks for them at your next pan or zoom. Until then the map can show only part of what that view holds, and the status line can say that it is showing all the features in view. This has been reached only in a test that puts the two events in that order by hand; it has not been seen in the running app.
