ITEM 62 (appended after item 61; byte-copied from the file):
62. **Each project the app saves leaves a folder in this machine's store, and nothing removes it.**
    The first save of an open dataset makes a new project identity and a folder for it in the machine store, `<data dir>/spatial-ide/projects/<32 hex>/`, where `<32 hex>` is the identity's 32 lowercase hex characters and `<data dir>` is the per-user data directory (on Windows, the folder the `LOCALAPPDATA` variable names). Every save of that open writes `locations.json` there, which holds the path at which this machine found the dataset. The first save also writes `folders.json`, which holds the folder the project was first saved to, as an absolute path, and an empty list of other folders. Both files are written before `project.spatial` is replaced, so a save that fails at the replace leaves them, and the next save of that open is a first save again and makes another identity and another folder. A dataset that is opened again and saved again also makes a new identity and a new folder at its first save. The app removes none of these folders or files.
