# what-counts-as-a-ruling

*Paraphrase, not the human's words: the binding text is at the source.*

Only an explicit selection or typed text is a ruling. [No preference], a dismissal or a timeout is no ruling: the item stays blocked and is asked again next round (the b21111d rule).

A red-line item accepts typed text only; it offers no preset option beyond "hold".
