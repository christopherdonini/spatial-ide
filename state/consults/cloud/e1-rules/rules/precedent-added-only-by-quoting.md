# precedent-added-only-by-quoting

*Paraphrase, not the human's words: the binding text is at the source.*

A precedent is added only by quoting an existing ruling; generalising beyond the ruling's words is a question, not a precedent. Each entry carries an id, the ruling verbatim with its date and source, a one-sentence generalisation, its scope and limits, and the cases it was applied to.
