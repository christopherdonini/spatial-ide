# record-classes

*Paraphrase, not the human's words: the binding text is at the source.*

Immutable, append-only: accepted ADRs, preregistration §§0–12 as filed, registered predictions, RESULTS sections, gate reports, every human ruling wherever it sits.

Current-state summaries, edited in place by PR: a STATUS.md, KNOWN-LIMITATIONS, PLAN.yaml, the queue, the ledger's status prose, briefs.

Generated evidence, only where a real generator exists (corpus tables, gate logs, hash manifests, the health strip): regenerated by script from a named revision, never hand-edited. A hand-written table is a summary, not evidence.
