# telegram-is-read-and-copy-only

*Paraphrase, not the human's words: the binding text is at the source.*

Telegram carries alerts and the question-round mirror only. It is never an answer channel: a reply typed into Telegram is not a ruling and is never read as one. Rulings arrive only through AskUserQuestion.
