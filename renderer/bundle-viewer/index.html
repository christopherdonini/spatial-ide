Provenance

No basemap. This bundle renders in its own projected CRS with no reprojection, and basemap tiles are Web Mercator — showing one would mean either reprojecting the data, which this bundle deliberately does not do, or drawing two coordinate systems on one canvas. This is the recorded consequence of the publishing path, not a missing feature.
This page verifies every asset the manifest lists. It cannot verify the code that is already running: the manifest's viewer hashes are for an external verifier, and the chain of trust does not close inside the browser.
